## 📖 Introduction

Single-cell RNA sequencing (scRNA-seq) is a powerful technique that enables the study of gene expression at the resolution of individual cells. Unlike bulk RNA sequencing, which provides an average expression profile across a population of cells, scRNA-seq captures cellular heterogeneity and allows the identification of distinct cell types and states within complex biological systems.

One of the most widely used platforms for scRNA-seq is 10X Genomics, which allows high-throughput profiling of thousands of cells simultaneously. However, the raw output generated by this platform is complex and requires multiple preprocessing steps before it can be used for downstream analysis.

The objective of this project is to process raw 10X Genomics sequencing data and generate a high-quality gene expression count matrix suitable for downstream analyses such as clustering, dimensionality reduction, and cell type identification.

---

## 🧪 Background Concepts

### 🔹 10X Genomics Technology

10X Genomics uses a droplet-based microfluidics system to isolate individual cells. Each cell is encapsulated into a droplet along with a gel bead containing unique barcode sequences.

Each sequencing read contains:
- **Cell Barcode (CB):** Identifies the cell of origin  
- **Unique Molecular Identifier (UMI):** Identifies individual RNA molecules and helps remove PCR duplicates  

Although millions of droplets are generated, most are empty. Only a small fraction contains real cells, making filtering a crucial step in the analysis.

---

### 🔹 STARsolo vs Cell Ranger

Two commonly used pipelines for processing 10X data are:

**Cell Ranger**
- Official pipeline developed by 10X Genomics  
- Produces standardized outputs  
- Computationally intensive and slower  

**STARsolo**
- Faster alternative integrated into the STAR aligner  
- Performs demultiplexing, alignment, and quantification  
- Produces results comparable to Cell Ranger  

In this workflow, STARsolo was used due to its efficiency and speed.

---

### 🔹 File Formats

- **FASTQ:** Contains raw sequencing reads  
  - R1 → Cell barcode + UMI  
  - R2 → cDNA sequence  

- **MTX (Matrix Market):** Sparse matrix storing gene expression counts  

- **HDF5:** Efficient format for storing large-scale data

## ⚙️ Methodology

### Step 1: Data Acquisition and Organization

The dataset used in this study consists of Peripheral Blood Mononuclear Cells (PBMCs) obtained from a healthy donor. The dataset includes FASTQ files containing sequencing reads, a gene annotation file (GTF), a barcode whitelist, and a reference genome (hg19).

All files were uploaded to the Galaxy platform and organized properly to ensure correct pairing of barcode (R1) and cDNA (R2) reads.

---

### Step 2: Identification of Library Chemistry

To correctly process the dataset, the chemistry version used during library preparation must be determined.

By examining the R1 FASTQ reads, the read length was found to be 28 base pairs. This corresponds to Chromium v3 chemistry, where:
- 16 bp represent the cell barcode  
- 12 bp represent the UMI  

Correct identification of chemistry is essential for accurate demultiplexing.

---

### Step 3: Demultiplexing, Alignment, and Quantification

The STARsolo tool was used to perform preprocessing.

First, demultiplexing assigns reads to individual cells based on barcode sequences. These barcodes are matched against a whitelist to ensure validity.

Next, the cDNA reads are aligned to the reference genome (hg19), determining the genomic origin of each read.

Finally, quantification is performed using UMI-based counting, which removes PCR duplicates and ensures accurate gene expression measurement.

Outputs generated include:
- BAM file (aligned reads)  
- Log file (mapping statistics)  
- Count matrix (matrix.mtx, genes.tsv, barcodes.tsv)  

---

### Step 4: Quality Control

Quality control was performed using MultiQC to assess alignment performance.

The analysis showed that approximately **87.5% of reads were uniquely mapped**, indicating high-quality sequencing and alignment.

This confirms that the dataset is suitable for downstream analysis.

---

### Step 5: Raw Count Matrix Evaluation

The output from STARsolo is a raw count matrix that includes all detected barcodes.

However, this matrix is highly sparse and contains:
- Empty droplets  
- Low-quality cells  
- Background noise  

Most values in the matrix are zero, making it unsuitable for direct analysis without filtering.

---

### Step 6: Filtering of Low-Quality Cells

Filtering was performed using the DropletUtils tool.

The DefaultDrops method identified **272 high-quality cells** based on predefined thresholds.

To improve filtering, the EmptyDrops method was applied using:
- Lower bound threshold: 200  
- False Discovery Rate (FDR): 0.01  

This resulted in **279 high-quality cells**, demonstrating improved sensitivity.

---

### Step 7: Barcode Rank Plot Analysis

A barcode rank plot was used to distinguish real cells from empty droplets.

The plot revealed:
- A knee point indicating transition between real cells and noise  
- An inflection point defining the filtering threshold  

Based on this, the expected number of real cells was between 200 and 400, which matches the filtered results.

## ⚠️ Limitations

Although this preprocessing pipeline provides a robust workflow for single-cell RNA-seq data, several limitations should be considered:

### 🔹 Dataset Limitations
- The dataset used is **subsampled (~300 cells)** instead of full 1,000 cells  
- This reduces biological diversity and limits detection of rare cell populations  

### 🔹 Reference Genome
- Analysis was performed using **hg19 (GRCh37)**  
- Newer genome builds like **hg38** provide improved annotation accuracy  

### 🔹 Technical Limitations
- No explicit **doublet detection** (e.g., Scrublet or DoubletFinder) was applied  
- **Ambient RNA contamination** was not corrected (e.g., SoupX, CellBender)  
- Only basic QC filtering was performed (no advanced multi-step refinement)  

### 🔹 Platform Constraints
- Galaxy training environment may limit:
  - Memory usage (chromosome-level processing in some cases)
  - Full dataset scalability  
- STARsolo was used in a simplified configuration to ensure reproducibility  

### 🔹 Biological Limitations
- Analysis is restricted to **PBMC dataset only**, limiting generalization to other tissue types  
- No downstream biological interpretation (clustering / annotation) was included in this pipeline
